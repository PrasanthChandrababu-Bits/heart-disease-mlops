# Short demonstration video checklist

Keep the recording concise and demonstrate:

1. Repository structure and setup instructions.
2. Dataset download, validation, and generated EDA.
3. Training both models and comparing the generated metrics.
4. MLflow runs, parameters, metrics, plots, and packaged model.
5. Passing tests and the successful GitHub Actions workflow.
6. Docker build, container startup, and a prediction request.
7. Minikube pods and services.
8. A prediction through the Kubernetes service.
9. Prometheus target/metrics and API request logs.
10. Architecture, limitations, and cleanup commands.

Do not expose authentication tokens or private account information.
